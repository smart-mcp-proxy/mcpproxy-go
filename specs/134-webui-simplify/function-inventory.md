# Function inventory: Web UI simplification

**Rule (spec R1, FR-065)**: every row below must have a place in the new layout and a test that activates it. A row with no place blocks the merge.

This file starts with the functions that two reviews of the spec (opencode `gpt-6.2-sol`, then `gpt-6.2-astra`, both against the frontend code on 2026-11-25) found at risk. Where the "What must be kept" text of a row offers a choice that includes retiring, replacing or relocating a function, the spec decides: the function is kept, with its present behaviour (R1). Maintainer decision 2026-11-25: Servers rows have no inline details and no "Details" link; where a row below asks for a row disclosure or a diagnostics link on the Servers list, its place is the first screen of server detail, reached from the server name. Maintainer decision 2026-11-25: the Viewing filter leaves the header; where a row below asks to keep it in the header or the phone overlay, its place is the page filter row (spec FR-016). It is a seed, not the full list: each pull request first adds every other function of the pages it touches, then fills "Place after" and "Test".
