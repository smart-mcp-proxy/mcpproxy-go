# Mockups for spec 134

The mockups are a design canvas artifact (private to the maintainer):

- Canvas, 25 screens: https://claude.ai/artifact/ME3Bv5Jmbg9jyGUwLNWe1Q
- Design system (tokens, components, content rules): https://claude.ai/artifact/71AA18hShTq1ibDmMB5Tzt
- Audit the design answers: https://claude.ai/artifact/DME4fgSCRrZbWAX57JvQ33

The mockups show default layouts only. `../spec.md` is the contract; where the two differ, the spec wins.

## Changing a mockup

Each screen is one `<Name>.dc.html` file in the artifact, generated by the scripts here.

1. `mkdir -p project && python3 gen/gen.py project` writes all screens into `project/` (not committed).
2. Edit the page body in `gen/pages.py` … `gen/pages4.py` (later files override earlier ones). `gen/gen.py` holds the shared shell (sidebar, header) and helpers (`btn`, `pill`, `tag`, `table`, …). `old/` holds three hand-written screens the generator reuses.
3. Regenerate, copy `canvas.json` into `project/`, and publish the changed files to the canvas artifact (paths `project/<Name>.dc.html`, `project/canvas.json`). To add a screen, also add it to `canvas.json` (`boards`, `order`).

## Changing the design itself

Change `../spec.md` first (and `../function-inventory.md` if a function moves), then the mockup. Rule R1 applies: no function may be lost. Review design changes with opencode `github-copilot/gpt-6.2-astra --variant high`, asking which existing function the change removes or hides.
