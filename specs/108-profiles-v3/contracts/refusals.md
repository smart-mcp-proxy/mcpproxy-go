# Contract: refusals and block reasons

Texts are exact (tests compare byte-for-byte after substituting `<server>`, `<tool>`, `<tier>`, `<cap>`). All are returned before any upstream I/O. **No agent-facing refusal names the profile's title or slug** (codex review round 1, research D27): the text is byte-identical whether the effective profile came from a pin, a binding, `anonymous_profile`, the URL or `set_profile`, so a refusal can never confirm that a caller is pinned or to what (the Spec 105 `set_profile` non-disclosure precedent, `internal/server/profile_tool.go`). The operator sees the profile on the activity record, in the explainer and in view-as.

| Anonymous caller while the binding guard is active (FR-008a runtime guard) | every MCP surface | deny-all scope: the Spec 105 non-disclosing out-of-scope shapes (identical to a dangling base) | as for a dangling base |

Precedence when several gates fail is exactly the explainer chain (data-model §7, FR-035): `credential → profile → server_in_scope → tool_rule → tier_cap → token_permission → global_gate → server_state → tool_approval`. `credential` fails only for revoked/expired/malformed credentials. `profile` fails only for a dangling base — a pin, switchable binding or `anonymous_profile` naming a missing profile (FR-020) — and for the FR-008a binding guard: the **canonical step and reason is `profile`** in the explainer (`first_failure: profile`), in view-as (`reason: profile`) and on the activity record (`block_reason` unset, `status=blocked` with the Spec 105 out-of-scope metadata); the agent-facing **shape** is the Spec 105 non-disclosing out-of-scope refusal, because a deny-all scope makes every server out of scope — the shape is not a second step value; `server_in_scope` uses the Spec 105 non-disclosing shape; `tool_rule`/`tier_cap` use the texts above; `token_permission` is the Spec 105 target-tier refusal; `global_gate` covers `read_only_mode`/`disable_management`/`enable_code_execution`. The explainer's `first_failure` follows this order, so it and the actual refusal agree (SC-009).
