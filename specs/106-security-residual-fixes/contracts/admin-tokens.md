# Admin Token Contract
GET /api/v1/admin/tokens: admin session/JWT only; list safe token metadata including owner user_id, name, prefix, scopes, permissions, timestamps, profile pin and revoked state. Never return hash or raw credential.
POST /api/v1/admin/users/{id}/tokens/revoke with JSON {"name":"exact stored name"}: canonical admin session/JWT-only route; treats the token name as opaque data so slash, percent, space and Unicode names remain addressable. The legacy /api/v1/admin/users/{id}/tokens/{name}/revoke route remains for URL-safe names. Revoke exact owner/name; 404 for unknown token, 503 if storage unavailable, generic 500 for storage failure. Repeated revocation succeeds. Other credentials and owners remain unchanged. Successful attempts log the authenticated actor, target owner, token name and outcome without raw credentials or hashes.
