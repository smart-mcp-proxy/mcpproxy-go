2. Viewer and paging PASS

views SKILL.md, pages a large file, and does not offer a binary file

SKILL.md opens in the text viewer (inert text). A 150 KiB file (data/large.txt of big) is read part by part in at least three parts: each Load more waits for its content response and for the rendered text to grow by that part. Every part is of the current copy, its digest equals the digest the core lists for that file in the current copy (the same digest the file row shows on screen), its size equals the listed size, its offset is where the previous part ended (in bytes, the first at 0) and its next_offset is where it ends; the last part has no next_offset and ends at the listed size. A binary file (logo.bin) is listed as binary, not shown, with no View button.
